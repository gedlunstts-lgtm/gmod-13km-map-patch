# Archive

These are the one-off scripts written while working this out: probes,
one-shot builders for intermediate versions, dead ends. They are here because
the project claims to be open, and leaving them out would hide most of how it
actually went.

They are **not** maintained and most will not run as-is: they carry absolute
paths from the machine they were written on, and they expect intermediate
build artefacts that are not in this repository. Read them as a record, not
as tools.

The parts worth reusing were cleaned up and moved to `lib/`. The naming is
chronological rather than meaningful - `mkeng05`, `mkvbsp09`, `portfull2` -
which is itself part of the record.
